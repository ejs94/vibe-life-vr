# Standalone hand profiles

The baked viewmodel hand is authoritative when a weapon has one. The standalone
hand is only for unarmed/free-offhand presence and is intentionally a simple
blocky glove, not a detailed model that tries to imitate a baked grip.

## Defaults

| Setting | Default | Meaning |
|---|---|---|
| `vr_hide_arms` | `0` | use the authored baked hands |
| `vr_holster` | `0` | `1` = hide the weapon and show the unarmed hand |
| `vr_hand_profile` | `auto` | standalone hand resolution |
| `vr_primary_hand_model` | `models/v_hand.mdl` | blocky open-hand presence |
| `vr_offhand_hand_model` | `models/v_hand.mdl` | free-offhand presence |
| `vr_hand_open_model` | `models/v_hand.mdl` | unarmed/open hand |
| `vr_hand_input_curl` | `0.35` | procedural finger input on the block hand |

The block hand is generated by `scripts/build_block_hand.py`. It uses the same
35-bone contract as the engine but is deliberately blocky: no false grip, no
claim of matching a baked hand. The mesh uses a short wrist cuff, a flatter
palm, and metacarpal connectors so the fingers do not float; it remains a
blocky presence placeholder, not an anatomical hand.

## Rules

- Weapon with baked hand: draw the baked hand; do not draw a floating hand.
- Unarmed: draw the block hand at the controller.
- Offhand free: draw the block hand at the controller.
- Offhand support: use the baked support hand when the weapon has one; do not
  pretend a block hand is gripping the foregrip.
- No per-weapon hand mesh or texture changes.
- No Rimrook/MMOD hand replacement in the default path.

## Validation

- `python3 scripts/check_hand_asset.py --model assets/valve_vr/models/v_hand.mdl`
- Monado suite includes the unarmed natural-hand test.
- Engine eye dumps are valid for the engine render; the Monado compositor
  target window is hidden during tests and is not counted as a visual pass.
